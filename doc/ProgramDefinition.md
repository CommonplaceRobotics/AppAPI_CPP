# Program Definition

From iRC V15.2 motion programs can be defined with a limited set of program commands via the app API. For earlier versions or more complex programs you can define a program as XML file, copy it to the robot and load it with the corresponding commands.

Note that this function currently only supports the most relevant commands for linear program execution. Branching, looping etc. is not supported.

## API
The base class ```AppClient``` provides the following methods for manipulating the main motion program that is loaded on the robot control. This does not change any program files, changes are lost when the program is unloaded or the robot is restarted.

* ```ClearMotionProgram()``` - Unloads the loaded motion program. Use this to clear the program before adding commands using ```AddMotionCommand()```
* ```AddMotionCommand()``` - Appends a single command to the end of the main motion program
* ```SetMotionProgram()``` - Unloads the loaded motion program and loads the given list of commands. Use this method to load a program that was generated by the app.

## Commands
Currently the following commands are supported. You may include all of them using header file ```RobotProgram/Command/Commands.h```.

### Motion
* ```Joint``` - Joint motion
* ```JointToCart``` - Joint motion to a cartesian position
* ```Linear``` - Linear motion to a cartesian position

### Logic
* ```CopyUserFrame``` - Copies a user frame to another. Use this to swap the frame for a pre-defined motion e.g. defined in a subprogram.
* ```Gripper``` - Open/close a gripper. The gripper must be defined by a tool configuration file.
* ```Pause``` - Pauses the motion program
* ```Stop``` - Stops the motion program
* ```SetDigitalOut``` - Sets a digital output on or off
* ```SetGlobalSignal``` - Sets a global signal on or off
* ```SetVelocity``` - Sets the speed of an external axis in velocity mode, e.g. for a conveyor.
* ```SubProgram``` - Calls a subprogram from a file that is stored on the robot control.
* ```Wait``` - Waits by duration or condition.
